**AI/ML Engineer. I build AI agents that run in production.**

Core engineer on TestGrid's CoTester, an autonomous testing agent shipped across nine versions to real customers. Python, LLM agents, computer vision. I write about what breaks when an agent meets the real world.

Site: [kadamlabs.com](https://kadamlabs.com) · Email: jay@kadamlabs.com · [LinkedIn](https://www.linkedin.com/in/kadamjay/)

## What I do

- **Agents that ship.** Not demos. I know what breaks when an LLM meets the real world, and how to keep it from breaking.
- **Plain English in, working output out.** Intent goes in, validated and executable steps come out, with the agent checking and repairing its own work before anyone sees it.
- **AI inside what you already have.** Models and agents wrapped into secure APIs and services a team can call on day one.
- **Python for anything repetitive.** Scraping, reports, document wrangling, data pipelines, glue between systems that were never meant to talk.
- **Vision and ML, end to end.** From labelling the data myself to running the model in production.
